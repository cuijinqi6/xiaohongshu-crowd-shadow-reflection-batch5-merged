# Crowd shadow and reflection dataset — merged batch 5

246 images numbered 301–546, consolidated from former batches 5, 6 and 7. Images retain their original dimensions; some have a long edge below 2K. The ZIP includes source records and original metadata.

Download all parts and `manifest.json`, then run `./reassemble.ps1` in PowerShell. The script checks each part and the reconstructed ZIP against SHA-256.

Images originate from Xiaohongshu; ownership and reuse rights have not been independently verified.
